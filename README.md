# materials-analysis-tools

## Research Context

This repository contains Python tools developed to support my undergraduate research in the Radiological Instrumentation Laboratory at UC Santa Cruz.

The analysis is being used for work on amorphous selenium–tellurium (Se–Te) multilayer photodetectors, including processing, plotting, and interpreting optical and electrical characterization data.

This work contributes to the project described in our accepted CPAD 2026 abstract:

**“Optical and Electrical Characterization of Multilayer Amorphous Selenium–Tellurium Photodetectors”**

The abstract focuses on the fabrication and characterization of amorphous Se/Se–Te multilayer detector structures with varying tellurium concentrations, with the goal of evaluating the optical, morphological, and compositional properties of these thin-film layers and supporting future development of staircase avalanche photodetectors.

Characterization methods used in the broader project include:
- Ellipsometry
- Photothermal deflection spectroscopy (PDS)
- UV–Vis spectroscopy
- Scanning electron microscopy (SEM)
- Energy-dispersive spectroscopy (EDS)

This repository is intended to make the data-processing workflow more reproducible and efficient as the project develops.
